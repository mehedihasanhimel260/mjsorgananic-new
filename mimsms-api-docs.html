MiMSMS Bulk SMS API
Fast & Reliable SMS Gateway for Bangladesh

This document provides instructions on how to quickly integrate MiMSMS communication services into various solutions using the MiMSMS REST API. All requests are submitted through POST (some via GET). We strongly recommend HTTPS for all requests so traffic is encrypted and privacy is ensured.

Base URLhttps://api.mimsms.com
Content-Typeapplication/json
AuthUsername + API Key
Authorization Headerbearer
POST https://api.mimsms.com/api/SmsSending/SMS
Send SMS

Send a single SMS to one destination. Phone number must be in international format without + sign (e.g. 8801844XXXXXX).

Headers
KeyValue
Authorizationbearer
Body (raw JSON)
KeyTypeRequiredDescription
ApiKeystringrequiredYour API Key from Developer Portal
MobileNumberstringrequiredDestination number (e.g. 8801844XXXXXX)
SenderNamestringrequiredYour registered Sender ID
UserNamestringrequiredYour registered email / username
TransactionTypestringrequiredT = Transactional  |  P = Promotional  |  D = Dynamic
MessagestringrequiredSMS message body
CampaignIdstringoptionalApproved campaign ID (required for Promotional)
CampaignNamestringoptionalCampaign name for reference
MessageIdstringoptionalCustom message identifier
SmsDatanulloptionalFor Dynamic SMS only; set null here
cURL
JavaScript
PHP
Python
Request
curl --location 'https://api.mimsms.com/api/SmsSending/SMS' \
--header 'Authorization: bearer' \
--data-raw '{
  "ApiKey":          "VTSJEXXXXXXXXXX9CL",
  "MobileNumber":    "8801844XXXXXX",
  "SenderName":      "iSMS",
  "CampaignName":    "",
  "UserName":        "abcd@example.com",
  "TransactionType": "T",
  "MessageId":       "",
  "Message":         "Welcome to MiM Digital",
  "CampaignId":      "null",
  "SmsData":         null
}'

POST https://api.mimsms.com/api/SmsSending/DSMS
Dynamic SMS

Send personalized messages to multiple destinations in one API call. Each entry in SmsData can carry a different message for each number.

Body (raw JSON)
KeyTypeRequiredDescription
UserNamestringrequiredYour registered email / username
ApikeystringrequiredYour API Key
SenderNamestringrequiredYour registered Sender ID
TransactionTypestringrequiredMust be D for Dynamic SMS
SmsDataarrayrequiredArray of { MobNumber, Message } objects
SmsData object
KeyTypeDescription
MobNumberstringDestination number in international format
MessagestringIndividual message text for this number
cURL
JavaScript
PHP
Python
Request
curl --location \
  'https://api.mimsms.com/api/SmsSending/DSMS' \
  --header 'Authorization: bearer' \
  --data-raw '{
    "UserName":        "abcd@example.com",
    "Apikey":          "VTSJXXXX9X9CL",
    "SenderName":      "018960iSMS50628",
    "TransactionType": "D",
    "SmsData": [
      { "MobNumber": "880184490xxxx", "Message": "Dynamic Messages 1" },
      { "MobNumber": "880171353xxxx", "Message": "Dynamic Messages 2" }
    ]
  }'
const res = await fetch(
  'https://api.mimsms.com/api/SmsSending/DSMS',
  {
    method: 'POST',
    headers: { 'Authorization':'bearer','Content-Type':'application/json' },
    body: JSON.stringify({
      UserName: "abcd@example.com", Apikey: "VTSJXXXX9X9CL",
      SenderName: "018960iSMS50628", TransactionType: "D",
      SmsData: [
        { MobNumber: "880184490xxxx", Message: "Dynamic Messages 1" },
        { MobNumber: "880171353xxxx", Message: "Dynamic Messages 2" }
      ]
    })
  }
);
console.log(await res.json());
